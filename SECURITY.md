# Política de segurança

## Como reportar uma vulnerabilidade

Não abra issue pública para falhas de segurança. Envie um e-mail para o responsável pelo projeto com:

- descrição do problema e o impacto esperado;
- passos para reproduzir (requisições, versão, navegador);
- se possível, uma sugestão de correção.

Você recebe a confirmação de recebimento em até **3 dias úteis**. Vulnerabilidades críticas recebem correção prioritária, numa versão `hotfix/*` publicada assim que estiver pronta. Pedimos que a divulgação pública só aconteça depois da correção.

## Escopo

Estão no escopo: a API (`backend/`), o app web/PWA (`frontend/`) e o firmware (`firmware/`). Os dados e as credenciais de demonstração são fictícios, gerados localmente e não servem para nenhum ambiente real.

As medidas de segurança adotadas estão descritas em [docs/SEGURANCA.md](docs/SEGURANCA.md).
